# 📡 CONTACT-0: THE DEAD FREQUENCY

> **A Sci-Fi Signal Decoding & Survival Experience**

A sci-fi mystery survival game set in deep space.

In **CONTACT-0: THE DEAD FREQUENCY**, you are an astronaut stationed in deep space. A mysterious signal emerges from the unknown. Decode the signal by aligning its **frequency, amplitude, and phase**, while defending the station from mysterious incoming spacecraft.

The deeper you go, the more uncertain the source becomes.

**Who — or what — is sending CONTACT-0?**

---

## 🎮 Gameplay

* 📡 Decode the mysterious **CONTACT-0** signal.
* 🎚️ Adjust **Frequency, Amplitude, and Phase**.
* 🌌 Monitor the incoming deep-space transmission.
* 🛰️ Defend the station from mysterious spacecraft.
* ⚡ Use the **PULSE** system to destroy incoming threats.
* 🛡️ Protect the station's integrity.
* ⏱️ Survive the mission timer.
* 🔍 Discover the mystery behind the unknown signal.

---

## 🧩 The Mystery

A strange signal has been detected from deep space.

Its pattern does not match any known transmission protocol.

While attempting to decode it, unknown objects begin approaching the station.

The signal becomes clearer.

The threats become closer.

And one question remains:

> **WHO — OR WHAT — IS SENDING CONTACT-0?**

## ✨ Key Features

### 📡 Signal Decoding

Match the signal's **frequency, amplitude, and phase** to decode the unknown transmission.

### 🛰️ Station Defense

Monitor incoming threats and protect the station using the **PULSE** defense system.

### 🌌 Sci-Fi Atmosphere

Experience a mysterious space-station environment with animated signals, spacecraft, sound effects, and cinematic events.

### 🏆 Mission System

Survive the mission, decode the signal, and reach the final outcome.

### 🎬 Cinematic Events

The game includes cinematic **Victory** and **Game Over** sequences based on the mission result.

## 📦 How to Play

1. Download the Windows build.
2. Extract the ZIP file.
3. Open the extracted folder.
4. Run `CONTACT-0-THE-DEAD-FREQUENCY.exe`.
5. Keep the `.exe` and `.pck` files in the same folder.
6. Start the mission.
